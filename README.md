# Tokopedia Chatbot
## Project Management Final Project
### How to use:
### Add bot to server: https://discord.com/oauth2/authorize?client_id=1317816186922340402&permissions=67584&integration_type=0&scope=bot.
### Use "!find" as initial prompt followed by a sentence. (Eg: Find me a cheap ricecooker from a trusted source)
### Wait for a couple of seconds and results will be sent by the bot.
